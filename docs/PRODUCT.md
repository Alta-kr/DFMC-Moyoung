# Moyoung 제품 기준

둔산제일교회 동호회 커뮤니티. 홈에서 모영/일정을 확인하고 상세 피드에서 게시글·일정·투표·댓글·하트/반응으로 참여한다.

## 보존할 규칙

- 역할: server_admin > head_admin > media_admin > 총무(is_leader, 모영당 최대 3명) > member > guest.
- 게스트는 홈 일정 참석/취소만 가능하다. 상세 피드, 관리자/총무 임명, 성도 검색 대상에서 제외한다.
- 기본 셀 ‘둔산제일교회’를 삭제/개편에서 보호한다.
- 홈 일정은 모영당 가장 임박한 1개다.
- 마감 투표는 홈/상단 고정에서 제외하고 타임라인으로 이동한다.
- 교회 전체 공지는 최신 1개만 유지한다.
- 기존 이미지 처리, 한국어 UI, 반응 종류를 유지한다.

## 전환 전 확정할 정책

회원 인증 목표는 Firebase 이메일/비밀번호다. 기존 계정 소유권과 uid 연결, 게스트의 안전한 신원 부여, 관리자 추가 인증의 유지/대체, 이메일 인증 전 허용 범위를 확정한다. 이름 일치만으로 관리자 권한을 승계하지 않는다.

역할을 admin/treasurer 문자열로 일괄 변경하지 않고 기존 역할/총무를 uid 기반 모델에 매핑한다. 탈퇴 시 작성물 보존/익명화 범위도 별도로 정한다.
