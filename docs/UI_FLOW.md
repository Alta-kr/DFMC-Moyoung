# 기존 화면과 목표 흐름

App.tsx는 URL query와 사용자 상태, LoginPage.tsx는 현재 로그인/게스트/OTP, LobbyPage.tsx는 홈, ClubDetailPage.tsx는 피드/참여, HeadAdminPage.tsx·ServerAdminPage.tsx는 관리를 담당한다. 새 라우팅 라이브러리로 재작성하지 않는다.

앱 시작 → Auth 복원 → 최소 프로필/멤버십 → 홈 summary. 공개 홈/게스트 정책을 유지하면서 안전한 신원 부여 방식을 확정한다. 사용자 변경 시 이전 캐시/구독을 정리한다.

가입: 이름·이메일·비밀번호 → Firebase Auth → 프로필 → 이메일 인증 안내. 프로필 실패 복구와 비밀번호 재설정을 제공한다. 관리자 추가 인증과 기존 회원 연결은 별도 전환 정책을 따른다.

모임 상세 → 통합 feed 첫 10개 → 스크롤/더보기 → cursor로 다음 10개. 기존 카드와 한국어 UI를 유지하며 상세 데이터는 필요할 때 조회한다. 정렬 기준은 서버 문서를 따른다.

참석·투표·댓글·하트/반응 → 즉시 UI 반영 → Firestore 쓰기 → 성공 확정 또는 실패 복구/재시도. 관리자 민감 작업은 Functions 검증 후 확정한다. 버튼 숨김만으로 권한을 구현하지 않는다. 로딩·빈 상태·권한 거부·재시도 오류를 구분한다.
